Custom axes
MONO · CASL · font-variation-settings

    
Beyond the registered five, a type designer can add axes of their own, named with four uppercase letters. Recursive has two. MONO slides from a proportional sans to a fixed-width monospace. CASL slides from a linear, neutral tone to a warmer, more casual one.

    
Custom axes have no CSS property of their own, so font-variation-settings is the only way to reach them.

    
.casual-mono {
  font-variation-settings: 'MONO' 1, 'CASL' 0.8;
}

    
You can also drive registered axes through this property with lowercase tags such as 'wght' and 'slnt'. Prefer the dedicated properties for those, since they inherit, transition and combine with the rest of your CSS in the way you expect. Keep font-variation-settings for the custom axes.

    
The property replaces rather than merges. If a later rule names only one axis, every other axis you set earlier falls back to its default. List all the custom axes you care about in one declaration.

Animating an axis
transition · @keyframes · @property

    
Axis values are numbers, so they can be transitioned and animated like any other. For a registered axis, animate the dedicated property. For a custom axis, animate font-variation-settings and list every axis you are animating in both states.

    

      

        
Hover or focus this heading

        
font-weight: 400 → 800, transition: font-weight var(--transition-base)

      

      

        
Proportional to monospace and back

        
@keyframes shift { to { font-variation-settings: 'MONO' 1 } }

      

      

        
Neutral to casual through a typed number

        
@property --casl, used as 'CASL' var(--casl)

      

    

    

      
    

    
.animated-heading {
  font-weight: 400;
  transition: font-weight var(--transition-base);
}
.animated-heading:hover { font-weight: 800; }

.shift {
  font-variation-settings: 'MONO' 0;
  animation: shift 4s ease-in-out infinite alternate;
}
@keyframes shift { to { font-variation-settings: 'MONO' 1; } }

@property --casl { syntax: '<number>'; inherits: true; initial-value: 0; }
.typed {
  font-variation-settings: 'CASL' var(--casl), 'MONO' 0;
  animation: warm 3s ease-in-out infinite alternate;
}
@keyframes warm { to { --casl: 1; } }

@media (prefers-reduced-motion: reduce) {
  .shift, .typed { animation: none; }
}

    
Each frame can force the browser to rasterize the glyphs again, which costs more than animating transform or opacity. Keep axis animation short and purposeful, and switch it off for visitors who ask for reduced motion. This page does exactly that.

  


  

    
One variable file versus a static bundle
file size tradeoff

    
A variable file carries interpolation data for its whole range, so it is larger than any single static weight. Whether it saves bytes depends on how many weights and styles the design really uses. Set that number below.

    

      
      
      2 weights
    

    

      

        

          One variable file
          

          112kb
        

        

          Static weight bundle
          

          48kb
        

      

    

    

    
Variable fonts win past a threshold, not every time. If the design only ever uses a regular and a bold, two static files are lighter than one variable file. Once the design reaches for several weights, or wants fluid weight as part of its type scale, the variable file pulls ahead and gives the whole range in between at no extra cost. Decide by how many cuts the design needs, not by assuming newer means lighter.

    
The static bundle is scaled from a 48kb size at two weights, which works out to 24kb per weight. Real files vary by font and subset.
